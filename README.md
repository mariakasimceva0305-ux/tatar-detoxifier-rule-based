# Tatar Detoxifier

## Кратко
Система очистки татарского текста на основе правил, словарей и подстрочных замен. Подход ориентирован на low-resource сценарий, где нет большого объёма качественно размеченных данных для обучения сложной модели.

## Задача
Нужно преобразовывать токсичные и нежелательные формы в более нейтральные варианты на татарском языке. В условиях ограниченных данных и ограниченного числа готовых моделей наиболее надёжным решением становится аккуратный набор правил и словарных замен.

## Что улучшено
- объединены несколько типов правил вместо одного источника замен;
- обработка построена так, чтобы учитывать как полные токены, так и подстрочные вхождения;
- словарные замены позволяют делать результат более управляемым и воспроизводимым.

## Архитектура
```text
[входной текст]
      |
      v
[нормализация]
      |
      +----------------------+----------------------+----------------------+
      |                      |                      |
      v                      v                      v
[правила по токенам] [правила по подстрокам] [словарные замены]
      |                      |                      |
      +----------------------+----------------------+ 
                             |
                             v
                   [объединение результатов]
                             |
                             v
                      [очищенный текст]
```

## Структура репозитория
```text
main.py                   точка входа
toxic_replacements.json   словарь замен
toxic_substrings.json     правила по подстрокам
```

## Критерии качества
- полнота удаления токсичных форм;
- точность замен без избыточной порчи нейтрального текста;
- устойчивость на коротких и шумных фрагментах;
- воспроизводимость результата.

## Ключевой вывод
Для low-resource языка управляемый конвейер на основе правил даёт предсказуемое поведение и позволяет быстро расширять покрытие за счёт словарей и дополнительных правил без полной переобучаемой модели.

## Ограничения
- правила нужно регулярно расширять по мере появления новых форм;
- возможны ложные срабатывания на неоднозначных подстроках;
- для более широкого покрытия в будущем потребуется сочетание правил и статистических методов.
