# Tatar Detoxifier

Детерминированный конвейер очистки токсичных фрагментов в татарском тексте. Решение использует словарные правила, правила по подстрокам и нормализацию текста.

## Назначение

Обнаруживать токсичные фрагменты в татарском тексте и заменять их на нейтральные варианты либо помечать для дальнейшей обработки.

## Архитектура

```text
Текст
  │
  ▼
Нормализация
  │
  ▼
Словарные правила
  │
  ▼
Правила по подстрокам
  │
  ▼
Замена или пометка
  │
  ▼
Очищенный текст
```

## Что реализовано

- нормализация входного текста;
- словарь замен для токсичных фрагментов;
- дополнительные правила по подстрокам;
- применение замен и формирование очищенного текста;
- словарные ресурсы для работы с татарским языком.

## Структура репозитория

- `main.py` — точка входа;
- `toxic_replacements.json` — словарь замен;
- `toxic_substrings.json` — правила по подстрокам;
- `tat_Cyrl_twl.txt`, `tt_ru_lexicon.csv` — языковые ресурсы;
- `paper.pdf` — сопроводительный материал.

## Оценка качества

При наличии проверочной выборки фиксируют:

- долю корректно обработанных токсичных фрагментов;
- долю ложных срабатываний;
- покрытие словарными правилами и правилами по подстрокам.

## Пример

```text
Вход:  ...
Выход: ...
```

## Запуск

```bash
python main.py
```

## Ограничения

- правила требуют ручного расширения;
- редкие формы слов и контекстные случаи могут обрабатываться неточно;
- для формального сравнения качества нужна отдельная размеченная выборка.
