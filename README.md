# Tatar Detoxifier

Детерминированный конвейер очистки токсичных фрагментов в татарском тексте. Решение использует словарные правила, правила по подстрокам и нормализацию текста.

## Задача
Нужно обнаруживать токсичные фрагменты в татарском тексте и заменять их на нейтральные варианты или помечать для дальнейшей обработки.

## Архитектура решения
```text
Текст
 │
 ▼
Нормализация
 │
 ▼
Словарные правила
 │
 ▼
Правила по подстрокам
 │
 ▼
Замена / пометка
 │
 ▼
Очищенный текст
```

## Структура репозитория
- `main.py` — точка входа;
- `toxic_replacements.json` — словарь замен;
- `toxic_substrings.json` — правила по подстрокам;
- дополнительные словарные ресурсы и примеры.

## Метрики
- доля корректно обработанных токсичных фрагментов;
- доля ложных срабатываний;
- покрытие словарём и правилами.

## Результаты
Если в репозитории есть проверочный набор примеров или тесты, в README нужно добавить:
- долю корректно обработанных случаев;
- число ошибок по типам;
- вклад словарных правил и правил по подстрокам.

Формат записи:
- `Правила по подстрокам повысили покрытие с ... до ...`
- `Доля ложных срабатываний составила ...`

## Пример
```text
Вход:  ...
Выход: ...
```

## Запуск
```bash
python main.py
```

## Ограничения и развитие
- Правила требуют ручного расширения;
- редкие формы слов и контекстные случаи могут обрабатываться неточно;
- следующий шаг — добавить воспроизводимую оценку качества на размеченной выборке.
